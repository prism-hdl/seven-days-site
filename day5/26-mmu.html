虚拟地址第一次成立
MMU39 + PTW：4 项 TLB、三级走表、缺页 12 / 13 / 15

第 20 集那颗 satp 只存不译，"三个消费出口留给第五日"——这一集接上消费者：39 位虚地址按三级页表翻成物理地址，4 项全相联 TLB 挡热路径，全核单份遍历引擎 PTW 走表；缺页按访问类型分 12 / 13 / 15 三种 cause 报出。命中与走表必须同果——这是 TLB 唯一真正的正确性不变量。

把 satp 的三个出口接上

第 20 集留了三个消费出口：mmu_en、mmu_root_ppn、mmu_asid。这一集它们各就各位：en 决定 Bare 直通还是 Sv39 翻译，root_ppn 给出根表物理页号，asid 进 TLB 的匹配键。翻译插在访存之前：LSU 送的虚地址先过 MMU 变物理地址再进 DCache；取指同款，I/D 两侧各例化一份查询器。

本模块独立于 CSR：en / root_ppn / acc / priv / mxr / sum / asid 全部从端口喂——核里由 csr 折叠 satp / mstatus / priv 给出。脱离 CSR 也能自证，是这一集判据能立起来的前提。

Sv39 的位域与三种缺页

prismwhitebow/iu/mmu.prism · Sv39 位域
// SV39（按 RISC-V 特权规范，位域以 openc910 ct_mmu_ptw.v 一手核对）：
//   39 位虚地址 = VPN[2](38:30) VPN[1](29:21) VPN[0](20:12) offset(11:0)
//   3 级：L2 叶=1GiB、L1 叶=2MiB、L0 叶=4KiB；每级一个 8 字节 PTE。
//   PTE 位域：V[0] R[1] W[2] X[3] U[4] G[5] A[6] D[7] RSW[9:8] PPN[37:10]（PA=40⇒PPN 28 位）
//   leaf 判据 = R|W|X 非 0；超级页对齐 = L1 叶要 PPN[8:0]=0、L2 叶要 PPN[17:0]=0
//   （对齐 C910 ptw.v:683-684）；缺页 cause：取指 12 / load 13 / store|AMO 15。

三条从位域里直接读出来：叶判据是 R|W|X 非零（三位全零是"下一级表的指针"）；超级页要对齐——2MiB 叶要求 PPN[8:0]=0、1GiB 叶要求 PPN[17:0]=0（对齐 C910 一手 RTL）；缺页按访问类型报号：取指 12、load 13、store/AMO 15——同一个空页，三种访问会报出三个不同的 cause，软件据此区分"该往哪边补页"。

分层：查询面每侧一份，遍历引擎全核一份

prismwhitebow/iu/mmu.prism · 分层与不变量
// 分层（v2 + Step 3 拆分）：
//   查询与定案在 MMU39（**每侧一份**：D 面在 LSU，I 面接取指时再例化一份）；
//   遍历引擎 PTW **全核一份**，I/D 两侧各用一组请求/交付口接它（D 压 I，起手后独占
//   到自己交付；请求侧被冲刷就 abort 撒手——不撒手会把引擎占死）。
//   命中 → 组合出 paddr（busy=0），一拍完事；未命中 → 请 PTW 走表，交付那一拍
//   （=PTW 读到末级 PTE 那一拍）锁存定案，下一拍 busy 落 0、结果保持到 req 撤。
//   权限/A-D/对齐的判定只在 MMU39 的 finalize 里走一遍：命中项与走表交付项汇成同一组
//   src_*，所以 hit 与 walk 必然同果（这是 TLB 唯一真正的正确性不变量，PTW 不碰定案）。

两处值得单说：一遍定案——权限、A/D 位、对齐的判定只在 MMU39 的 finalize 里走一遍，命中项与走表交付项汇成同一组 src_*，所以"命中"与"走表"必然同果；PTW 只负责"把 PTE 搬回来"，不碰定案。这是 TLB 唯一真正的正确性不变量。单引擎的仲裁照 C910 ct_mmu_arb 的形状：D 侧压 I 侧，起手后独占到自己交付为止；请求方被冲刷就 abort 放弃请求——不放弃会把引擎占死。

TLB：4 项全相联，sfence 一拍清

prismwhitebow/iu/mmu.prism · TLB 口径
// TLB（v2 简化，拍板点②/⑥）：
//   4 项全相联；TAG 存 {level, global, asid, vpn27}；DATA 存 {flags(8), ppn(28)}；
//   valid 用 u4 位掩码（sfence 一拍抹 0，不与 mem 单写口冲突）。
//   命中：VPN 前缀按 level 比（4K 比 27、2M 比 18、1G 比 9）；ASID 严格匹配，
//   但 global=1 跨 ASID。
//   Victim：round-robin，r_victim 每填一次自增。
  • 全相联、4 项：不分路、不散列，VPN 前缀直接跟 4 项挨个比——4KiB 比 27 位、2MiB 比 18 位、1GiB 比 9 位（大页只比自己那一段前缀）。
  • ASID 严格匹配，但 global=1 跨 ASID：内核映射打了全局旗的页，换进程不必重走表。
  • valid 用 u4 位掩码：sfence 一拍把 4 位抹 0——绕开 mem 的单写口，不必逐项清。
  • 回填只缓存"成功"的叶 PTE：fault 不缓存（下次仍重走表）；victim 轮转（r_victim 每填一次自增）。

查询侧端口：一次把输入面看全

prismwhitebow/iu/mmu.prism · 查询侧端口
    // ---- 查询侧 ----
    in  req       : Signal<u1>      // 翻译请求有效（保持到 busy 落 0）
    in  en        : Signal<u1>      // 0=Bare 直通，1=SV39 翻译
    in  vaddr     : Signal<u39>     // 39 位虚地址
    in  acc       : Signal<u2>      // 0=取指 1=load 2=store/AMO
    in  priv      : Signal<u2>      // 特权级：0=U 1=S 3=M
    in  mxr       : Signal<u1>      // mstatus.MXR：load 可读 X=1 页
    in  sum       : Signal<u1>      // mstatus.SUM：S 态可访问 U 页
    in  root_ppn  : Signal<u28>     // satp.PPN：root 表物理页号
    in  asid      : Signal<u16>     // satp.ASID（TLB 按 ASID 匹配，见拍板点⑥）
    in  sfence    : Signal<u1>      // 1=全清 TLB（v1 语义，拍板点②）

端口表就是这份"翻译契约"：地址（39 位虚）、访问类型、特权上下文（priv 含 3=M 态该走直通）、两道页级权限开关（mxr / sum）、根表与 ASID、以及清表请求。

判据：94 拍 92 组，七发反证各打一根柱子

行内期望 94 拍 / 92 组，家族覆盖：Bare 直通、4KiB 三级、V=0、2MiB 大页与错位、1GiB 巨页、权限矩阵（R-W-X · U · SUM · MXR）、A/D 位，加上 TLB 六条（命中≡走表、大页前缀、ASID 严格、global 跨 ASID、sfence 全清、命中拍重算权限）与两条定案判据（只认它交付的那条 VPN、同页换偏移 paddr 跟着走）。

七发反证，每条只让对应那一族判红：①–② PTW（超级页对齐 / Svade 的 A/D）；③–⑥ TLB（忽略 ASID、sfence 空操作、大页按整 27 位 VPN 比、命中路径整体失效）；⑦ 定案不比 VPN（held 漏到别页）。另有 mmu_dc_check：PTW 经冷 DCache 走表（mem_ready 握手），终值按页表镜像手算——反证把 mem_ready 改接常量 1（等价于握手断线），期望必须判红。核级探针（mmu_cpu_probe）把整段 S 态代码跑在翻译页上：取指过 ITLB、走表读命中页、sw 写命中页再从另一条 VA 读回、数据缺页与取指缺页两发分流（x13 就是那条指令的 PC、scause=12），判据里还有一条逐拍序列——走表期间 rd 一帧 PTE 都不许进。

小结

  • satp 三个出口接上消费者：Bare 直通 / Sv39 三级翻译，翻译插在访存（与取指）之前。
  • 叶判据 R|W|X 非零；超级页对齐按 C910 一手值；缺页 12 / 13 / 15 按访问类型报号。
  • MMU39 每侧一份、PTW 全核一份（D 压 I、被冲刷要放弃请求）；定案只有一处（finalize），命中≡走表是唯一真不变量。
  • TLB 4 项全相联、ASID 严格 + global 跨 ASID、valid 位掩码 sfence 一拍清、只回填成功的叶。
  • 判据：94 拍 92 组 + 七发反证 + 冷缓存走表 + 核级探针（含"rd 不得写入 PTE"的逐拍序列）。

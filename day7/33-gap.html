差在五处
五级顺序单发射 vs 现代高性能核

第六日的白虹把 Linux 送进了 shell——那是一台"一条道、走到底"的机器：一拍一条、按序不回头、访存一停全停。这一集把它的样子和它在第七日长成的样子摆上同一张桌，把差量成五处、再把差立成三个可自证的数。不造硬件，只把"差在哪"量清楚。

"天地万物都造齐了。" —— 《创世记》 2:1

两台机器，放在同一张桌上

第六日结束时，白虹是一台五级流水、单发射、按序执行的机器，它把 Linux 送进了 shell——这是实打实的成绩。它的形状里藏着四条写死的假设：一拍只译码一条；"在流水里的位置"就是指令的年龄；存储器的读是组合的、同拍出数；任何一个部件在等，整条流水线陪着停。

这四条假设换来的是简单：裁决表小、前递两级就够、缓存不需要握手。它们也换出一句天花板：每拍最多退休 1 条；而且一条 load 去等存储器，后面所有的指令都陪着等。第七日，白虹换了个形状。

第六日的白虹

五级流水 · 单发射 · 按序提交 · 命中组合出数 · 占用即停顿。成绩：OpenSBI、Linux 到 shell。

第七日的白虹

主干 12 级 · 四发乱序（译码 3 / 重命名 4 / 提交 3）· ROB 64 · 非阻塞访存 + 私有 L2 · 四件套预测。成绩：CoreMark 同频归一到 A76 那一档。

这一集不动烙铁：两台机器摆上桌，先把"差在哪"量清楚——差在五处。接下来五集各拆一处，最后一集把跑分摆上来。

四条现状，各有代码作证

说"旧"不能靠形容词。四条假设，各抽一段真代码出来看。

① 一拍一条

整台机器的节拍写在 @schedule 里——五级、每级一拍：

prismwhitebow/whitebow.prism · 节拍
@schedule WhitebowCpu {
    bitwidth  : { data:64 }
    pipeline  : 5 stage
    reset     : async_low
    clock     : 100 MHz, domain = single
    resource  : none
    latency   : 5 cycle
}

五级之间是四颗边界寄存器，一拍只流过一条指令。"每拍退休条数"的硬上限就是 1——之后无论把缓存做多大、时钟做多快，这个 1 不动。想动它，先动形状。

② 位置即年龄

EX 段要操作数时先看它现在在哪。前递只做两级——按在流水里的位置分档：

prismwhitebow/iu/hazard.prism · 前递
    fwd_a = match {
        (mem_reg_wen & (mem_rd != 0) & (mem_rd == ex_rs1)) => 1,
        (wb_reg_wen  & (wb_rd  != 0) & (wb_rd  == ex_rs1)) => 2,
        _                                                  => 0,
    }

同一条操作数可能同时挂在两处（同一颗寄存器被连续两条指令写）。按序执行下，EX/MEM 里那条一定更年轻，所以先选它——"位置排序"能替代"年龄排序"，全靠按序。乱序之后这个等式就塌了：同一个位置的条目未必是老的（第 34 集拆这一处）。

③ 组合读出数

缓存和存储器一样，读是组合的——命中即出数、不占拍：

prismwhitebow/iu/icache.prism · 头注
// =============================================================================
// icache.prism — 指令缓存（直接映射，16 行 × 每行 4 字）
//
// 容量 64 字 = 256 字节；行大小 4 字（16 字节，装得下 4 条标准指令或 8 条 RVC）；
// 直接映射，无替换策略；命中组合读出（同拍出，与 im 的 1RW 口径一致）。

数据侧同款口径：命中同拍出数，未命中只认一笔在途事务，然后把整条流水线冻到数据回来。"读得干脆"与"等得彻底"是一枚硬币的两面——第 37 集要把这枚硬币翻过来。

④ 占用即停顿

会"停"的事，白虹列成了一张十行的表（八停顿 + 两冲刷）：

prismwhitebow/iu/hazard.prism · 停与冲的十个源
    src_fetch = icache_miss
    src_load  = load_use
    src_div   = div_hold
    src_fdiv  = fdiv_hold
    src_dmiss = dcache_miss       // 可缓存 load 未命中 ∨ 填充中（含检出拍，见 dcache.prism 的 busy）
    src_mmiss = mmu_miss          // MMU 走表未定案：与 dcache 占用同款形状（load/store 就站在 EX/MEM 里等翻译）
    src_amo   = amo_miss          // AMO 读/写相位未走完：同款形状（读交付前/写落地前都要占住）
    src_mis   = mis_miss          // 未对齐拆两笔：第一笔只拿到半个操作数，第二笔落地前放走就是拿半字当全字
    src_br    = ex_redirect
    src_trap  = mem_except

八个停顿源合成一根 hold_fe——一压压全流水；两个冲刷源负责把走错的推测杀回来。这十行是这一日全部工程的原材料：第 34–38 集要动的就是它们；第 39 集的计数器，也按这十个事件编号。

五处差异

把两台机器逐维摆开，差在五处：

维第六日的白虹第七日的白虹拆在
乱序按序不回头；前递按"级的位置"分两档重命名 + ROB 64 + 分队列发射；年龄改用 tag 记EP 34
多发射一拍一条：译码、提交都是单口取指 3 / 译码 3 / 重命名 4 / 提交 3；寄存器堆与递交口成组加宽EP 35
深流水五级；级间靠组合读直接取数主干 12 级；前端 4 级 + 指令缓冲；缓存改同步读、打拍出数EP 36
访存命中组合出数；miss 冻整条；直接映射 512B4 路 64KB、write-back；非阻塞（地址 8 + 填充 2 在途）；私有 L2 512KB；对外 AXI4EP 37
预测BTB + BHT 按 PC 猜；误预测冲 2 拍L0-BTB + BTB 1024×4 + 双表 BHT + IND-BTB；RAS 12 项EP 38

五处不是五个独立选项，是一条线上的五个结：多发射让一拍最多要读八个操作数——寄存器堆端口与旁路网络跟着成倍长；深流水让误预测的代价变贵——先把预测器升级再谈加深；非阻塞访存的收益只有乱序能兑现（miss 期间"还能退休几条"是第 37 集的判据）；而乱序要成立，先得有 ② 那条"年龄"的新记法。顺序拆得开，改动拆不开。

先立三个数——不靠形容词

"差很多"不算结论。三个数互证：一个看总量，一个看构成，一个看潜力。

数① 每拍退休条数（IPC）

固定 600 拍窗口实测：有退休的 472 拍、空的 128 拍——IPC 0.787。单发射的天花板是 1.0，它就在头顶上。

数② 空拍率与按源归因

128 拍空拍占 600 拍的 21.3%。关键不是这个百分比，而是每一拍空拍都能被上表十个源里的至少一个解释——这叫归因闭合：归因按"或"覆盖，不许对不上账；对不上就按拍打印十个源的取值，直接点名缺了哪一类。判据要写成"什么情况下它会红"——"覆盖率 ≥95%"那种写法永远不会红。这套账本已经有硬件对应：十个源 + 两个缓存起手在 csr 里各有计数器（mhpmcounter3–14 固定绑定，事件号即位序），第 39 集把它接到跑分上。

数③ miss 期间，还能退休几条

第三个数第一、二代机器没有：从一笔 load miss 发出、到数据交付的整段里，还能退休几条指令。按序核这个数恒为 0——miss 就是"全停"，没有第二种可能；只有非阻塞的机器才第一次给出非零值。它是第 37 集唯一诚实的度量。

三个数怎么读 ① 与 ② 描述"现在慢在哪"；③ 描述"换形状之后能快在哪"。改动前后各跑一遍同一张归因表——收益兑现不兑现，当场可见。

五处各要动多深

  • 乱序（第 34 集）：把"位置即年龄"换成"tag 即年龄"——重命名、ROB 64、分队列发射、访存队列，四件一起上；恢复靠一次整表写回，不做快照。
  • 多发射（第 35 集）：宽度是全机参数——译码 3、重命名 4、提交 3；寄存器堆端口成组；相邻指令先融合——收益记在后面几档的账上。
  • 深流水（第 36 集）：主干 12 级——先把"读"改成打拍出数，前端拆成四级加指令缓冲；误预测惩罚、前递级距、栅栏生效拍数全部重算。
  • 访存（第 37 集）：非阻塞 DCache（地址 8 + 填充 2 在途）、写合并缓冲、私有 L2 512KB、对外换 AXI4——miss 期间，流水继续退休。
  • 预测（第 38 集）：返回地址栈（12 项，由退休推送）+ 四件套：L0-BTB、BTB 1024×4、双表 BHT、IND-BTB。

然后（第 39 集）跑分：CoreMark 两档 + Dhrystone，同频归一后与 A76 对着看。

小结

  • 第六日的白虹（五级 · 单发射 · 按序）与第七日的白虹（12 级 · 四发乱序）——差在五处：乱序、多发射、深流水、访存、预测。
  • 四条现状各有代码出处：一拍一条（@schedule）、位置即年龄（两级前递）、组合读出数（缓存头注）、占用即停顿（十个源）。
  • 三个可自证的量：IPC 0.787（600 拍窗）、空拍 21.3% 且逐拍闭合归因、miss 期间可退休拍数（按序核恒 0）。
  • 接下来五集各拆一处，改动前后跑同一张归因表——先立判据，再动烙铁。
